# Sovereign AI 201 lab

This 75-minute path continues the presentation architecture through eight learner-owned checkpoints. A 15-minute recovery allowance brings the Launchpad reservation target to 90 minutes.

Run the package validator with:

```bash
npm run verify:lab
```

The fixtures are rehearsal evidence and deliberately carry `REHEARSAL` source labels. They teach result shape and failure handling; they never certify a live deployment.
