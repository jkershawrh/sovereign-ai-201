# 5. Prove the changed condition

## Objective

Show that sensitive personal data bound for an unapproved region is denied before inference.

## Build

Change only destination and data classification, evaluate the same policy, and save the result as `denied-result.json`. Source state: a rehearsal denial proves lab mechanics, not a live platform control.

## Verify

Require `DENY`, a named rule or reason, and a null inference result. Any generated model response fails this checkpoint.

## Learner checkpoint

Explain why the changed evidence—not model preference—changed the outcome.
