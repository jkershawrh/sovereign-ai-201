# 8. Export the review package

## Objective

Leave with a reviewable implementation artifact rather than a completed-screen assertion.

## Build

Create `review-package.json` linking preflight, declaration, model identity, allow, deny, proof, and failure records. Include source state and collection time for every item.

## Verify

The package must name the final human owner, unresolved evidence, and next qualification depth. Source state: mixed packages preserve each item’s original label.

## Learner checkpoint

Present the one-sentence conclusion: policy constrained the workload, Intel Xeon served the approved model, and independently verifiable evidence supports—but does not authorize—the decision.
